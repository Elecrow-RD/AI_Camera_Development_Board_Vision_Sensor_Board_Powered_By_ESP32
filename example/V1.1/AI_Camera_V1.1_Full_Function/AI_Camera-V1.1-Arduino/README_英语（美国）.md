# AI_Camera
## Introduction
AI_Camera serves as an entry point that integrates online AI recognition and an AI chatbot, leveraging the capabilities of large AI models to provide image recognition and online conversations.
## Features
- Supports sending and recognizing images over HTTP
- Supports the WebSocket communication protocol
- Uses the OPUS audio codec
- Voice interaction based on a streaming ASR + LLM + TTS architecture
- LCD display with support for displaying expressions
- Device control through device-side IoT (volume, lighting, GPIO, etc.)
## Hardware Version
- Supported production hardware version: AI_Camera V1.1
## Development Environment
- Arduino IDE 2.3.4
- ESP32 version: 3.2.0
- Developed in a Windows environment
